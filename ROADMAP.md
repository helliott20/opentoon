# OpenToon Roadmap

Tracking parity with Toon Boom Harmony Advanced.

## Done
- [x] Project model (scene, layers, cels, exposure xsheet)
- [x] Paperless raster drawing engine
- [x] Brush / pencil / eraser with pressure
- [x] Shape tools + fill + eyedropper
- [x] Select + free transform (move / scale / rotate)
- [x] Multi-layer compositing with opacity
- [x] Timeline / xsheet with exposure editing
- [x] Onion skinning
- [x] Color palette + HSV picker
- [x] Playback engine (loop / ping-pong)
- [x] Camera framing + camera keyframes
- [x] Cut-out animation: per-layer transform keyframes (position / scale / rotation)
- [x] Transform-aware drawing, compositing, onion skin and export
- [x] Undo / redo history
- [x] Save / load `.otoon` projects + autosave
- [x] Export GIF / WebM / PNG sequence
- [x] Vector drawing layers (smooth spline strokes, de-jitter smoothing)
- [x] Auto-connect: stroke endpoints snap together to close line art
- [x] Smart paint bucket: fills enclosed regions with gap closing + hover highlight
- [x] Vector stroke editing (eraser splits strokes, select / move / delete)
- [x] Copy / cut / paste drawings between frames and layers
- [x] Timeline drag editing — move cels, drag to extend exposure
- [x] Playback in/out range
- [x] Flip canvas horizontally / vertically
- [x] Timeline drawing thumbnails
- [x] Audio soundtrack — import, waveform, synced playback
- [x] Video import — extract frames to a reference layer (+ its audio)
- [x] Grid, rule-of-thirds guides, symmetry / mirror drawing
- [x] Desktop app (Electron) with over-the-air auto-updates
- [x] Manual "Check for Updates" + version display in About
- [x] Wacom pen eraser-flip — flip the stylus to erase
- [x] Canvas resize after drawing (scale artwork or crop / extend)
- [x] Drag the timeline ruler to set the project frame count
- [x] Tool & view settings persist between sessions

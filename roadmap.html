Reliability & polish — issues found in review

Items found during the source review. Recently fixed: autosave now writes a real file on disk (no storage-quota limit); MP4 export and audio-in-export landed; the desktop app opens .otoon files by double-click; recent files, incremental save and revert-to-saved were added; pen pressure is curve-adjustable; canvas rotation, a customizable shortcut editor and workspace layout presets shipped; settings persist; Wacom eraser-flip works; the laggy vector eraser is throttled; and the right-click / context-menu / status-bar-clipping bugs are resolved. Remaining items:

  • Medium Video export records in real time. MP4 / WebM export drives a MediaRecorder one frame at a time, so a long scene takes as long as it plays. A frame-accurate encoder would be faster and exact.
  • Low No global error surface. Errors land in the console only; the unsigned installer also triggers a one-time SmartScreen warning until the build is code-signed.
